# LinePilot Resume Bullets

Use one version, not both. Each version contains exactly three bullets. Re-run the benchmark before using Version B on a resume; numbers are environment-specific.

## Version A — No benchmark metrics

- Built a digital queue management application with Java 21, Spring Boot, PostgreSQL, React, TypeScript, Tailwind CSS, REST APIs, and Server-Sent Events for customer token tracking and staff operations.
- Implemented explicit queue-state transitions and concurrency-safe call-next processing with PostgreSQL row locks, transactional services, daily token uniqueness constraints, and database-backed staff authorization.
- Added Flyway migrations, paginated history, moving-average wait estimates, RFC 7807 error handling, PostgreSQL Testcontainers integration tests, Docker Compose, OpenAPI documentation, and GitHub Actions CI.

## Version B — Benchmarked

- Built a Dockerized digital queue management application with Java 21, Spring Boot, PostgreSQL, React, TypeScript, Tailwind CSS, REST APIs, and Server-Sent Events for customer and staff workflows.
- Prevented duplicate concurrent claims with PostgreSQL `FOR UPDATE SKIP LOCKED`, transactional state transitions, and uniqueness constraints, recording 0 duplicate assignments and 0 failures across 120 call-next requests in three local benchmark runs.
- Delivered committed queue snapshots to five connected SSE clients per run with 93.93 ms median and 121.74 ms p95 update latency across 300 measured samples on the documented local environment.
